Corner Bloom Fractal (Interactive 3D Expansion)

Controls

  • UP Arrow - Increase recursion depth
  • DOWN Arrow - Decrease recursion depth
  • LEFT Arrow - Decrease rotation
  • RIGHT Arrow - Increase rotation
  • W - Increase shrink factor
  • S - Decrease shrink factor
  • SPACE - Toggle animation
  • R - Reset to default settings

  • D - Add a new 3D layer (adds one layer every 3 presses)
  • A - Remove one 3D layer
